This lesson highlights the pieces of the Excel interface you will reach for constantly. Consider it a map before we start translating Python ideas into spreadsheets.

## The Ribbon

The ribbon is the toolbar at the top of the window. Each tab (Home, Insert, Data, Formulas, etc.) groups related commands.

For analysis work, you will live in:

- **Formulas**: function library, named ranges, and formula auditing.
- **Data**: sorting, filtering, validation, and data import.
- **Home**: quick formatting, number styles, and alignment.

## The Grid

The grid is the heart of Excel. It is a matrix of rows (numbered) and columns (lettered). Every cell has an address like `A1` or `C5`.

## Formulas

Formulas drive Excel’s calculations. Each one starts with `=` and references other cells by address. For example, to add `A1` and `B1`, type `=A1 + B1` in another cell and press Enter.
