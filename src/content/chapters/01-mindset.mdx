Excel is not a general-purpose language like Python, yet it remains a powerhouse for everyday analysis. Python lets you script multi-step pipelines; Excel gives you a visual canvas that recalculates instantly as you edit cells.

Think of an Excel workbook as a living script pointed at one table at a time. Formulas flow down the grid, and the interface keeps feedback immediate. Python scripts, meanwhile, tend to load data, transform it, and save or visualize results in batches.

Despite their different vibes, the analysis loop is identical:

1. Load data.
2. Transform columns step by step.
3. Summarize the results.
4. Visualize or export findings.

The rest of this course simply matches each stage to its Python and Excel expression.

<Callout>
By the end, you will glide between Python and Excel with the same mental model—choose the tool that fits the moment, not the one you happen to know best today.
</Callout>
