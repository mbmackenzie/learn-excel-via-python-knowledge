## Practice

### 1. Total Study Hours

Add `homework_hours` and `lab_hours` together for each student. Store the result in a `total_hours` column or variable.

<PairView pair="practice-total-hours" />

### 2. Passing Flag

Create a column `passed_test` flag that is "Yes" for scores `>= 70` and "No" otherwise.

<PairView pair="practice-pass-flag" />


### 3. Letter Grade

Translate `test_score` into a letter grade: `A (90+)`, `B (70+)`, otherwise `C`. Store the result in a `letter_grade` column or variable.

<PairView pair="practice-letter-ifs" />

### 4. (Bonus) Class Average


Calculate the class average for `test_score`.
